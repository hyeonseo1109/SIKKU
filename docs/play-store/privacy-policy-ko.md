# 시꾸 개인정보처리방침 초안

- 운영자: `[운영자 이름 입력]`
- 문의: `[문의 이메일 입력]`
- 시행일: `[시행일 입력]`
- 공개 주소: `[공개 HTTPS URL 입력]`

시꾸: 나만의 시계 꾸미기(이하 “앱”)는 사용자가 직접 선택한 사진을 시계 프로젝트와 Android 홈 화면 위젯을 만들기 위해 처리합니다.

## 처리하는 정보와 목적

앱은 사용자가 시스템 사진 선택 화면에서 고른 사진, 가공된 투명 PNG와 미리보기, 시계 배치·스타일 설정, 위젯별 프로젝트 연결 정보를 처리합니다. 로그인 정보, 연락처, 위치, 광고 ID는 처리하지 않습니다.

## 저장 위치와 외부 전송

프로젝트와 이미지는 기기의 앱 전용 저장소에, 위젯 설정은 Android의 앱 전용 설정 저장소에 보관됩니다. 현재 코드에는 운영자 서버, 광고, 분석, crash reporting SDK가 없으며 해당 데이터를 외부 서버나 제3자에게 전송·제공하지 않습니다.

## 보존과 삭제

정보는 사용자가 해당 프로젝트를 삭제하거나 앱 데이터를 삭제할 때까지 보관됩니다. 프로젝트 삭제 시 연결된 원본 복사본·가공 이미지·미리보기도 함께 삭제 대상이 됩니다. 앱 설정의 전체 삭제 기능이 제공되기 전까지는 Android 시스템 설정의 “저장공간 및 캐시 → 저장공간 삭제” 또는 앱 삭제로 전체 로컬 데이터를 삭제할 수 있습니다. 앱 삭제 시 Android 정책에 따라 앱 전용 데이터가 삭제됩니다.

## Android 권한

앱은 재부팅 후 홈 위젯 갱신을 복원하기 위해 부팅 완료 권한을 사용합니다. 사진은 사용자가 이미지 추가 기능을 실행했을 때 시스템 선택기를 통해 고르며, 전체 사진 라이브러리 권한을 상시 요청하지 않습니다.

## 정책 변경

기능 또는 데이터 처리 방식이 바뀌면 이 문서를 갱신하고 시행일을 표시합니다. 출시 전 placeholder를 실제 정보로 교체하고 공개 HTTPS 주소에 게시해야 합니다.
