# App Content 제출 초안

- 앱/게임: 앱
- 카테고리: 맞춤설정 또는 도구(Play Console 제공 항목에서 최종 선택)
- 광고: 없음
- 앱 액세스 제한: 없음, 로그인 불필요
- 타깃 연령: 아동 전용으로 설계하지 않음
- 뉴스/건강/금융/정부 앱: 해당 없음
- 광고 ID: 사용하지 않음
- 계정 삭제: 계정 기능이 없어 해당 없음
- 사용자 제작 콘텐츠 공유: 없음
- 사진 접근: 사용자가 고른 이미지로 로컬 시계를 만들기 위한 목적
- 정확한 알람/알림 권한: 사용하지 않음

콘텐츠 등급 설문과 타깃 연령은 운영자가 Play Console에서 실제 대상 사용자에 맞게 확정한다.
