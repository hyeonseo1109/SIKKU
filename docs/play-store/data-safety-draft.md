# Data Safety 작성 초안

코드 감사 기준으로 앱 서버, 광고, 분석, crash reporting SDK는 없다. 사용자가 고른 사진과 시계 프로젝트 JSON은 앱 전용 로컬 저장소에만 복사된다. 위젯 설정은 Android `SharedPreferences`에 로컬 저장된다.

## Play Console 답변 검토안

- 수집 또는 제3자 공유: 앱 개발자 서버로 전송되는 데이터 없음
- 사진 및 동영상: 사용자가 시계 제작을 위해 명시적으로 선택하며 기기 안에서만 처리
- 앱 활동, 기기 ID, 광고 ID, 위치, 연락처, 금융/건강 정보: 처리 코드 없음
- 계정: 로그인과 계정 생성 없음
- 전송 중 암호화: 서버 전송 자체가 없음
- 삭제: 프로젝트 개별 삭제 또는 앱 삭제로 로컬 데이터 삭제

Google Play의 “수집” 정의와 배포 시점 dependency가 바뀔 수 있으므로 제출 직전에 최종 AAB와 SDK 목록을 다시 확인한다. Photo Picker/시스템 파일 선택기는 Android 시스템 UI이며 앱은 사용자가 선택한 항목만 가져온다.
