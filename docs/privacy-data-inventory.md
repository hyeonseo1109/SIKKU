# 개인정보 및 로컬 데이터 목록

| 데이터               | 목적                       | 위치                                           | 외부 전송 | 삭제                  |
| -------------------- | -------------------------- | ---------------------------------------------- | --------- | --------------------- |
| 사용자가 선택한 사진 | 시계 배경·레이어·숫자 제작 | 앱 전용 `document/projects/{projectId}/assets` | 없음      | 프로젝트 삭제/앱 삭제 |
| 가공 PNG와 미리보기  | 편집·목록·위젯 표시        | 앱 전용 프로젝트 폴더                          | 없음      | 프로젝트 삭제/교체 시 |
| 프로젝트 JSON        | 시계 설정 복원             | 앱 전용 프로젝트 폴더                          | 없음      | 프로젝트 삭제/앱 삭제 |
| 프로젝트 목록 인덱스 | 홈 목록 로딩               | AsyncStorage                                   | 없음      | 프로젝트/앱 삭제      |
| 위젯별 설정          | 홈 위젯 복원               | Android SharedPreferences                      | 없음      | 위젯/프로젝트/앱 삭제 |

Android 자동 백업은 현재 비활성화했다. 클라우드 복원은 제공하지 않는다.

## 개인정보처리방침 게시용 필수 입력

앱 이름, 운영자 법적 명칭, 문의 이메일, 시행일을 입력한 뒤 공개 HTTPS 페이지로 게시해야 한다. 정책에는 사진 선택 목적, 로컬 저장, 서버 미전송, 제3자 제공 없음, 보존과 삭제 방법, 앱 삭제 시 데이터 삭제 가능성을 포함한다. 실제 URL이 없으므로 코드에 가짜 링크를 넣지 않았다.
